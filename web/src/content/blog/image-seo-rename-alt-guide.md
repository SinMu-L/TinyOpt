## 01. Google 如何理解你的图片

Google 不"看"图片，它通过以下信号理解图片内容：

1. **文件名** — `blue-widget.webp` 比 `IMG_8392.webp` 包含更多信号
2. **Alt 文本** — `<img alt="blue widget side view">` 是最强信号
3. **周围文字** — 图片前后的段落文字
4. **页面标题和 H1** — 页面主题相关性
5. **结构化数据** — Product、Recipe 等 Schema 标记

文件名是你能完全控制的第一信号，也是最容易被忽略的一个。

## 02. 批量重命名：让 500 张图文件名自动包含关键词

## 03. Alt 标签的批量策略

文件名只是第一步。WordPress 等 CMS 在上传图片时会自动用文件名填充 Alt 文本（去掉连字符和序号）。

如果你的文件名是 `bluetooth-earbuds-001.webp`，WordPress 默认 Alt 就是 `bluetooth earbuds 001`。虽然不是完美的人类语言，但已经远好于空白。

更好的策略：在 TinyOpt 重命名时把最关键的两个关键词写进文件名，上传到 WordPress 后再配合 SEO 插件（如 Rank Math、Yoast）批量优化 Alt 文本。

## 04. 图片 SEO 的完整检查清单

每次发布新内容前，给图片跑完这个清单：

```
□ 文件名包含目标关键词（用连字符分隔）
□ 图片格式为 WebP（JPEG fallback）
□ 宽度不超过 1200px（正文图）或 400px（缩略图）
□ 压缩到 < 150KB
□ Alt 文本包含关键词 + 自然描述
□ 使用 <picture> 标签提供多格式兼容
□ 在 sitemap 中包含图片 URL
```

## 05. 结构化数据：图片 SEO 的进阶玩法

如果你的页面是产品页、文章页或食谱页，加结构化数据可以触发 Google 的富媒体搜索结果（包括放大后的图片）。

Product Schema 示例中的图片标记：

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "image": [
    "https://yoursite.com/images/bluetooth-earbuds-001.webp",
    "https://yoursite.com/images/bluetooth-earbuds-002.webp"
  ],
  "name": "Bluetooth Earbuds"
}
</script>
```

注意这里的图片 URL 应该指向你优化后的 WebP 版本，而不是原始大图。

## 常见问题

**01. 改了文件名后，之前索引的图片会怎样？**

Google 会重新抓取并更新索引。旧的 URL 会返回 404，如果你改了图片路径，需要用 301 重定向。更好的做法：在新文章上线前就完成重命名和压缩。

**02. 图片文件名用中文还是英文？**

Google 对中英文文件名都能识别，但英文文件名（用连字符分隔）是最保险的选择。对于中文站点，文件名用英文关键词 + 中文 Alt 文本是最优组合。

**03. 带水印的图片会影响图片搜索排名吗？**

微透明的水印不影响。大面积、遮盖主体内容的水印可能会降低用户体验，间接影响点击率而非排名。建议水印透明度设在 15-25%。

**04. 多大尺寸的图片最容易获得展示？**

Google 推荐图片至少 1200px 宽以获得最佳展示效果。但头像、缩略图等小图按实际用途设置即可。关键是保持宽高比不变形。

**05. TinyOpt 批量重命名后能自动配 Alt 文本吗？**

TinyOpt 重命名的是文件名。上传到 WordPress 等 CMS 后，大多数主题会自动提取文件名作为默认 Alt。你需要再去批量编辑页面手动优化 Alt 文案。
