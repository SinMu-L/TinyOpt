你在 Shopify 上架了 50 款新产品。每款 5 张图，总共 250 张。你的流程是什么？

A：用 PS 一张张压缩、调尺寸、另存为 WebP，然后逐个上传。耗时：一下午。
B：用 TinyOpt 批量拖进去，设好参数，点一下「开始压缩」。耗时：3 分钟。

如果你选了 A，这篇文章就是为你写的。

## Shopify 产品图的三座大山

Shopify 官方对产品图有明确的性能建议，但大多数卖家忽略了它们。结果就是页面加载慢、PageSpeed 低分、转化率损失。

### 1. 图片体积过大

Shopify 建议产品图控制在 200KB 以下，缩略图 50KB 以下。但大多数产品图都是从相机或手机直接导出的，单张 2-5MB 很常见。

一个 50 款产品的店铺，如果每张原图 3MB，首页一次加载 10 张产品图就是 30MB。理论上移动端用户要等 30 秒才能看全——实际上他们 3 秒就走了。

### 2. 图片尺寸不统一

不同来源的产品图尺寸五花八门：2000x3000、4000x3000、800x1200……Shopify 主题的缩略图网格要求统一的宽高比。尺寸不一致要么导致图片被裁切（产品被切掉），要么导致页面布局混乱。

### 3. 文件命名混乱

`IMG_3829.jpg`、`DSC_0001.jpg`、`照片 001.jpg`……这些文件名对 Google 来说毫无意义。而 `wool-coat-grey-size-m.jpg` 这样的文件名本身就是 SEO 资产——Google 图片搜索和 Google Shopping 都会利用文件名理解图片内容。

## TinyOpt 全流程方案

### 第一步：批量压缩（核心步骤）

打开 TinyOpt，将 250 张产品图拖入「压缩任务」页面：

1. **设置输出格式**：选择 WebP（体积比 JPEG 降低 60-70%，画质几乎无损）
2. **设置缩放模式**：选择「适配」，宽高设 2048x2048（Shopify 推荐的最大产品图尺寸）
3. **设置输出目录**：指定一个文件夹，避免覆盖原图
4. **点击「开始压缩」**：多 API Key 并发，250 张图约 3 分钟完成

压缩结果：原图 2-5MB → 压缩后 WebP 80-180KB，体积减少 90%+，肉眼完全看不出区别。

### 第二步：批量重命名（SEO 优化）

切换到「重命名」标签页：

1. 模板设置：`{name}-{index}`
2. 文件名模板：把每张图按产品名预先命名好文件夹
3. 使用 `{index}` 变量自动补序号，格式例如 `wool-coat-grey-01.webp`

这样处理过的产品图文件名就是 SEO 友好的。Google 爬虫抓到这些图片时，能从文件名直接推断内容，更容易出现在「羊毛外套」的图片搜索结果里。

### 第三步：上传到 Shopify

压缩好的 WebP 文件体积小，上传速度快。注意两点：

1. **Shopify 原生支持 WebP**：直接上传 WebP 文件，Shopify 会自动处理兼容性（对不支持的浏览器自动回退 JPEG）
2. **Alt 标签**：上传后记得在 Shopify 后台给每个产品图填写 Alt 标签（图片说明），这是产品图 SEO 的第二道保险

## 实操建议

1. **先备份原图**：压缩后的图不可逆，原图保留一份
2. **多 Key 叠加**：TinyPNG 免费 API Key 每月 500 张，注册多个 Key 在 TinyOpt 中添加，自动轮转提升额度
3. **输出格式选 WebP**：除非有特殊兼容性需求（如发给第三方平台要求 JPEG），默认选 WebP
4. **善用缩放**：如果你的 Shopify 主题要求 1:1 正方形产品图，选择「裁剪」→ 1:1 比例一键批量裁

250 张产品图，从处理完到上传完毕，一个午休的时间就够了。把省下来的半天时间拿去选品、写文案、做推广——那才是真正赚钱的事。
