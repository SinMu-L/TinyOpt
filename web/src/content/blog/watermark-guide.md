## 02. 拖拽定位：所见即所得

水印位置不用输入坐标。在预览区直接把水印拖到想要的位置：

- **右下角**：最常用的位置，不影响主体观看
- **居中**：防盗效果最好，但遮挡画面
- **平铺**：高价值素材专用，裁剪也剪不掉

工具会自动处理边距（默认 20px），水印不会超出图片边界。位置、透明度、缩放都是实时预览，拖一下就看得到效果。

## 03. 水印参数怎么调才专业

透明度建议：
```
产品展示图 → 60-70%（不太显眼但能看清版权）
作品集预览 → 40-50%（平衡美观与保护）
高价值素材 → 30-40% + 平铺（防裁剪盗用）
```

文字大小：图片宽度的 3-5%
推荐字体：微软雅黑、思源黑体、Arial
字体颜色：白色为主，搭配半透明背景阴影

## 常见问题

**01. 可以批量给不同图片加不同的水印吗？**
当前版本一次任务只能使用一种水印配置。如果需要不同水印，可以分多次执行。

**02. 水印位置会随图片尺寸变化吗？**
会。水印位置基于图片宽高的比例坐标系统，同一配置在不同尺寸图片上都会保持在相对位置。

**03. 支持透明 PNG 水印吗？**
支持。图片水印使用 PNG 格式效果最好，透明区域会保持透明。

**04. 水印能旋转角度吗？**
当前版本不支持旋转。建议在外部工具中预先旋转好水印图片再导入。

**05. 原图会被覆盖吗？**
不会。水印处理后的图片默认输出到 `compressed/` 子目录，原文件保持不变。
