> **Experience（体验）** — 基于真实使用场景的实操分享

1. 在软件中切换到「水印工具」标签页
2. 选择水印类型（我这次用的是图片水印）

4. 在预览区域拖拽到理想位置（右下角）
5. 调节透明度到 70%，缩放比例 10%
6. 点击「开始添加水印」

## 二、水印工具的核心设计

> **Expertise（专业度）** — 深入解析技术实现

### 2.1 三种水印类型

| 类型 | 适用场景 | 优势 |
|------|---------|------|
| **图片水印** | Logo、品牌标识 | 支持透明背景 PNG，保留原始色彩 |
| **文字水印** | 版权声明、URL | 支持任意 Windows 字体，灵活调整 |
| **图文混合** | 品牌 Logo + 版权文字 | 一次性完成双重保护 |

### 2.2 可视化拖拽定位

水印位置通过 `calc_watermark_position` 算法实现，核心逻辑如下：

- 基于图片宽度和高度的比例坐标系统（0-1 区间）
- 自动边缘限制（默认 20px 边距），确保水印不溢出
- 实时渲染预览，所见即所得

### 2.3 透明度与缩放

- **透明度**：0-100% 可调，70% 左右是兼顾可见与美观的最佳值
- **缩放比例**：相对于原图宽度的百分比，建议 8-15%

## 三、专业建议：水印放置的最佳实践

> **Authoritativeness（权威性）** — 基于行业经验的专业推荐

### 3.1 位置选择

根据版权保护研究，水印放置应考虑：

- **右下角**：最符合阅读习惯，干扰最小（默认推荐）
- **居中**：防盗图效果最好，但影响观赏体验
- **平铺**：适合高价值图片，彻底杜绝裁剪盗用

### 3.2 透明度策略

```
产品展示图 → 透明度 60-70%
作品集 → 透明度 40-50%（兼顾美观与保护）
高价值素材 → 透明度 30-40% + 平铺
```

### 3.3 文字水印排版

- 推荐使用微软雅黑或思源黑体
- 字号建议为图片宽度的 3-5%
- 字体颜色以白色为主，搭配半透明背景

## 四、透明说明

> **Trustworthiness（可信度）** — 坦诚的功能边界说明

- 水印功能完全在本地处理，图片不会上传到任何服务器

- 处理后的图片保存为高质量 JPEG（quality=95），在文件大小与画质间取得平衡
