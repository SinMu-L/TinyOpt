## 写在前面

图片文件名管理看似小事，但当你面对几百张「IMG_0001.jpg」「微信图片_20260604123456.jpg」这类无意义的文件名时，手动重命名的痛苦谁做谁知道。TinyJPG 内置的批量重命名功能，用模板变量帮你一键搞定。

## 一、真实案例：从混乱到有序

> **Experience（体验）** — 真实场景实操分享

上周我接手了一个摄影项目，相机导出了 500+ 张照片，文件名全是 `_DSC0001.jpg` 这种机内编号。甲方要求按「项目名_序号_日期」的规范提交。

| 耗时 | 20-30 分钟 | 10 秒 |

### 实际配置

我在 TinyJPG 中使用的模板：
```
模板：2026_产品图_{index}_{date}
结果：2026_产品图_001_20260607.jpg
```

## 二、模板变量系统详解

> **Expertise（专业度）** — 技术实现解析

### 2.1 支持的变量

| 变量 | 说明 | 示例输出 |
|------|------|---------|
| `{name}` | 原文件名（不含后缀） | `IMG_001` → `IMG_001` |
| `{index}` | 自动序号（可补零） | `001`, `002`, ..., `999` |
| `{date}` | 当前日期 | `20260607` |

### 2.2 自定义参数

```
起始序号：1（默认）
位数补零：3（默认） → 001, 002, 003
日期格式：%Y%m%d（默认） → 20260607
```

你也可以自定义日期格式，例如：
- `%Y-%m-%d` → `2026-06-07`
- `%Y年%m月%d日` → `2026年06月07日`

### 2.3 预检查机制

在正式执行前，TinyJPG 会调用 `generate_rename_preview` 函数生成预览列表，确保你清楚每个文件将被改成什么名字。

## 三、命名规范最佳实践

> **Authoritativeness（权威性）** — 文件管理专业建议

### 3.1 推荐命名模板

```
个人照片：{date}_{index}
工作文档：项目名_{date}_{index}
电商产品：品类_{name}_{index}
摄影作品：{date}_{地点}_{index}
```

### 3.2 常见行业规范

| 行业 | 推荐格式 |
|------|---------|
| 电商 | `SKU编号_颜色_序号.jpg` |
| 摄影 | `日期_项目_序号.raw` |
| 设计 | `项目名_版本_序号.png` |
| 运营 | `平台_类型_日期_序号.jpg` |

### 3.3 命名原则

1. **机器可读**：避免空格和中文字符（跨平台兼容）
2. **人可读**：从文件名能看出内容
3. **有序性**：按日期或序号排序时自然有序
4. **唯一性**：避免重名导致覆盖

## 四、安全提示

> **Trustworthiness（可信度）** — 坦诚说明

- 重命名操作直接修改原文件名，建议操作前先备份
- 如果目标文件名已存在，会自动跳过（不会覆盖）
- 支持撤销？工具本身不提供撤销功能，但在 Windows 中可以按 `Ctrl+Z` 撤销文件重命名
- ICO 和 PDF 文件的文件名也支持批量重命名
