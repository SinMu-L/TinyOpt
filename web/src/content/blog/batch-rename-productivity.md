## 01. 模板变量：三个就够了

TinyJPG 提供三个变量，覆盖 90% 的命名需求：

| 变量 | 含义 | 示例输出 |
|------|------|---------|
| `{name}` | 原文件名（不含后缀） | `IMG_001` → `IMG_001` |
| `{index}` | 自动编号（可补零位） | `001`, `002`, ..., `999` |
| `{date}` | 当前日期 | `20260607` |

**我那次的实际配置**：
```
模板：2026_摄影项目_{index}_{date}
结果：2026_摄影项目_001_20260607.jpg
     2026_摄影项目_002_20260607.jpg
     ...
```

## 02. 进阶配置

起始序号可以从任意数字开始，不是非得从 1：
```
起始序号：100 → 101, 102, 103...
```

日期格式按你的习惯调整：
```
%Y%m%d → 20260607（默认）
%Y-%m-%d → 2026-06-07
%Y年%m月%d日 → 2026年06月07日
```

执行前有预览列表，确保每个文件的新名字都正确再确认。

## 03. 行业命名参考

```
电商商品：SKU_{颜色}_{index}.jpg
摄影交付：{date}_{项目}_{index}.jpg
设计切图：{项目}_{版本}_{序号}.png
运营素材：{平台}_{类型}_{date}.jpg
```

通用的命名原则：
- **机器可读**：避免空格和特殊字符
- **人可读**：看文件名就知道内容
- **有序性**：按日期或序号排序时自然有序
- **唯一性**：不会覆盖已有文件

## 常见问题

**01. 可以按拍摄时间命名吗？**
当前版本使用文件的修改时间或当前日期。拍摄时间（EXIF）暂不支持。

**02. 序号补零可以改吗？**
可以。默认 3 位（001），可以在设置中改为 2 位（01）或 4 位（0001）。

**03. 改名后原文件还在吗？**
重命名直接修改原文件，改名后原名字不存在。建议先备份。

**04. 支持子文件夹内文件吗？**
当前版本只处理直接拖入的文件列表，不会递归扫描子目录。

**05. 可以和压缩一起用吗？**
可以。在压缩任务中启用重命名选项，压缩和水印同步完成。
