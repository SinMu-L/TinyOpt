## v1.3.0 更新内容

TinyJPG 批量压缩助手 v1.3.0 正式发布！本次更新带来了以下改进：

### ✨ 新增功能

1. **AVIF 格式支持** — 新增 AVIF 图片格式输出，在保持画质的同时获得更小的文件体积
2. **格式转换升级** — 目前支持 9 种格式互转：JPEG、PNG、WebP、GIF、TIFF、BMP、AVIF、ICO、PDF

### 🎨 优化改进

- 水印拖拽体验大幅优化，操作更加流畅
- API 配额显示优化，支持实时刷新
- 压缩队列管理改进，批量处理更稳定

### 🐛 Bug 修复

- 修复在高 DPI 屏幕下的界面显示问题
- 修复部分特殊图片格式解析失败的问题
- 修复水印预览在某些情况下的渲染异常
