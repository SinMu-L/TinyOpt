设计师的日常充满了各种文件格式转换：给前端切图要导出 WebP，给客户看稿要转 PDF，Favicon 要 ICO，印刷文件要 TIFF。

每种格式用一个工具的话，你的电脑上可能装了 Photoshop、格式工厂、在线转换器、命令行 ffmpeg 等五六个软件。切换成本很高，而且每个工具的操作逻辑不一样，容易出错。

TinyOpt 支持 9 种输入格式和 7 种输出格式的组合，一个工具覆盖设计师日常 90% 的格式转换需求。

## 9 种输入 × 9 种输出矩阵

| 输入格式 | 可输出为 |
|---------|---------|
| JPG, PNG, WebP, AVIF, BMP, GIF, TIFF | JPEG, PNG, WebP, GIF, TIFF, BMP, AVIF, **ICO**, **PDF** |

特殊格式 ICO 和 PDF 只能作为输出，不能作为输入（BMP 可输入并自动转 PNG）。

## 01. 一键生成网站 Favicon（ICO）——前端设计师必备

每个网站都需要一个 Favicon（浏览器标签页上的小图标），格式必须是 ICO。

传统做法：
1. 在 PS/AI 里画好图标
2. 导出 PNG 或 SVG
3. 打开在线转换器上传
4. 下载 ICO
5. 可能还要手动切成 16×16、32×32、48×48 三个尺寸

TinyOpt 的做法：
1. 拖入 PNG 图标文件
2. 输出格式选 **ICO**
3. 自动生成 256×256 RGBA 的 ICO（兼容所有尺寸）

更高效的是：你可以把一个多尺寸的 PNG 直接缩放 + 转格式一次完成。例如原始图标 512px，在 TinyOpt 里设置缩放到 256px 同时输出为 ICO。

## 02. 客户预览 PDF——不用打开 AI 和 PS

给客户看设计稿的时候，PDF 是最通用的格式。但如果你的源文件是 PNG 或 JPEG（比如截图稿、摄影稿），导出 PDF 通常要打开 Photoshop 或 Illustrator。

TinyOpt 直接在压缩任务中输出 PDF：150 DPI、RGB 色彩、标准 PDF 格式。拖入几张图片，输出格式选 PDF，得到一个多页 PDF 文件。

适用场景：
- 网站设计稿截图 → 一个 PDF 传给客户审阅
- Banner 多版本提案 → 一个 PDF 对比查看
- 电商产品图册 → 多页 PDF 给供应商参考

## 03. 格式转换 + 压缩：为什么应该在同一个工具里做

多数工具的流程是：先在一个软件里编辑/转换格式 → 再换一个工具压缩 → 再检查效果。

但每次编码/解码都是有损操作。TinyOpt 的思路是 **转换格式和压缩一次完成**：读取原图 → 直接按目标格式编码并压缩 → 输出。中间少一次编解码，画质保留更好。

举个极端例子：一张 JPEG 原图 → 转 PNG → 再压缩。两次有损/无损混用可能导致色块或文件异常变大。但如果一次性从 JPEG 转 WebP + 压缩，路径最短，结果最优。

## 04. 9 种格式，什么场景用什么

| 输出格式 | 最佳场景 | 典型输出用途 |
|---------|---------|------------|
| WebP | Web 前端 | 网站图片、移动端 H5 |
| AVIF | 高性能前端 | 首屏 Banner、图片密集型站点 |
| JPEG | 兼容优先 | 邮件、微信发送、老版本 App |
| PNG | 透明/像素精确 | UI 切图、截图、Logo |
| ICO | 图标 | Favicon、Windows 桌面图标 |
| PDF | 交付/预览 | 客户审阅、印刷厂打样 |
| TIFF | 印刷/归档 | 高质量印刷、长期存档 |
| GIF | 动图 | 简单动图（复杂动图用 WebP） |
| BMP | 兼容 | 不推荐用于 Web |

## 不只是格式不同——效率也不同

设计师的工作被分割在太多工具之间。格式转换只是其中一环，但恰恰是最容易被"多工具碎片化"的一环。

## 常见问题

**01. 转 ICO 只能输出 256×256 吗？**

TinyOpt 输出的 ICO 是 256×256 RGBA 格式。浏览器的 Favicon 显示会自动缩放到需要的尺寸（16×16、32×32 等），一个 256px 的 ICO 足以覆盖所有场景。如果你需要特定尺寸，可以配合缩放功能设置目标宽度。

**02. PDF 输出能不能设置页边距和布局？**

TinyOpt 的 PDF 输出是纯图片 PDF，不包含文字编辑功能。图片会撑满整个页面（150 DPI、RGB）。如果需要高级排版，建议导出为 PNG 后放入 AI/InDesign 排版。

**03. 彩色空间（CMYK/RGB）在转换时会丢失吗？**

TinyOpt 的格式转换和压缩引擎工作在 RGB 色彩空间。如果你的图片是用于印刷的 CMYK 文件，建议在转换前确认色彩需求。JPEG 和 WebP 格式天然不支持 CMYK。

**04. 能批量把整个文件夹转成不同格式吗？**

一个转换任务只能输出一种格式。如果你需要同一批图同时输出 WebP 和 AVIF 两个版本，需要分两次执行。注意分次执行时需要重新读取原图，建议保留原始文件。

**05. BMP 格式有必要保留吗？**

对于 Web 和数字产品，不建议使用 BMP。BMP 是无压缩格式，体积通常是 JPEG 的 10 倍以上。TinyOpt 支持 BMP 输出主要是为了兼容旧系统，日常工作中应优先选择 WebP 或 JPEG。
