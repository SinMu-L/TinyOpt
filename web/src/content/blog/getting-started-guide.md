第一次打开 TinyOpt 时，我手上正好有 150 张活动照片要上传公司 CMS。每张 5MB 左右，后台限制单文件最大 2MB。试过改后缀、用画图缩小，效果都不行。

朋友推荐了 TinyOpt。下载、申请 Key、拖入图片、点击压缩——从安装到跑完 150 张，**不到 10 分钟**。输出文件平均 400KB，画质看不出区别。

如果你也是第一次用，下面三个步骤走完就能上手。

## 01. 下载并安装

去[下载中心](/download/)获取最新版安装包。双击安装，启动后你会看到三个标签页：「压缩工具」「水印工具」「设置」。

不需要注册账号，不需要登录。下载完直接用。

## 02. 申请并配置 API Key

TinyOpt 用 TinyPNG 的 API 做压缩，需要申请一个免费 Key：

1. 打开 [TinyPNG 开发者页面](https://tinypng.com/developers)
2. 输入姓名和邮箱，提交
3. 去邮箱查收 API Key
4. 复制 Key，在 TinyOpt 中点击「设置」→「API Key 管理」→「添加 Key」

每个邮箱每月免费 500 张。不够用的话，可以注册多个邮箱配合使用——参考[多 Key 管理指南](/zh/blog/multi-key-management/)。

👉 [还没下载？先下载 TinyOpt](/download/)

## 03. 开始第一次压缩

1. 回到「压缩工具」标签页
2. 点击「添加图片」或直接把图片拖入窗口
3. 右侧面板选择输出格式（默认 JPEG）
4. 压缩模式选「适配模式」——按宽度等比缩放，最常用
5. 点击「开始压缩」
6. 等待进度条跑完

输出文件默认保存在原文件旁边的 `compressed/` 目录下。

### 压缩参数速查

```
网页用图 → 适配模式，宽度 1920px，JPEG Q85
电商主图 → 适配模式，宽度 1200px，JPEG Q80
社交分享 → 适配模式，宽度 1080px，JPEG Q90
打印输出 → 原尺寸，PNG 或高质量 JPEG
```

## 04. 注意事项

- 建议单次不超过 500 张（考虑 API 月度限额）
- 压缩时可最小化窗口到系统托盘，不影响其他工作
- 网络不稳定时工具会自动重试，不需要手动干预
- ICO 和 PDF 格式不支持水印（格式限制）

## 常见问题

**01. 必须要有自己的 API Key 吗？**
TinyOpt 内置了 2 个共享 Key，打开就能用。但共享 Key 可能被多人使用，建议自行注册一个专用 Key。

**02. 压缩后图片会变模糊吗？**
TinyPNG 采用智能有损压缩，移除人眼不易察觉的颜色数据。绝大多数情况下肉眼看不出区别。

**03. 支持哪些图片格式？**
输入支持 JPG、PNG、WebP、AVIF、BMP、GIF、TIFF。输出支持 9 种格式（含 ICO 和 PDF）。

**04. 可以在多台电脑上用吗？**
可以。TinyOpt 是绿色软件，把文件夹拷到另一台电脑就能用（需要配置 API Key）。

**05. 有 Mac 版吗？**
目前仅支持 Windows。Mac 和 Linux 版本暂无计划。
