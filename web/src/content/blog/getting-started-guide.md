## 写在前面

如果你是第一次使用 TinyJPG 批量压缩助手，本文将带你完成从下载到成功压缩第一张图片的全过程。整个过程只需 3 分钟。

## 一、我的第一次使用经历

> **Experience（体验）** — 真实用户场景

我第一次使用 TinyJPG 时，手里有 150 张活动照片需要压缩上传到公司 CMS。每个文件都在 5MB 左右，后台限制单文件最大 2MB。当时试过直接改文件后缀、用 Windows 自带画图缩小尺寸，效果都不理想。

朋友推荐了 TinyJPG，我抱着试试看的心态下载了。从安装到跑完 150 张图片，整个过程不到 10 分钟，输出文件平均只有 400KB，画质肉眼几乎看不出区别。之后它就变成了我电脑上的常驻工具。

## 二、分步教程

> **Expertise（专业度）** — 操作步骤详解

### 第一步：下载与安装

1. 前往 [下载中心](/download/) 下载最新版 Windows 安装包
2. 双击运行安装程序，按提示完成安装
3. 启动软件，你会看到简洁的主界面，分为「压缩工具」「水印工具」「设置」三个标签页

### 第二步：获取 TinyPNG API Key

TinyJPG 依赖 TinyPNG 官方 API 进行压缩，因此需要先申请免费的 API Key：

1. 打开 [TinyPNG 官网](https://tinypng.com/developers)
2. 输入你的姓名和邮箱地址
3. 点击提交，API Key 会发送到你的邮箱
4. 复制 Key，回到 TinyJPG，点击「设置」→「API Key 管理」→「添加 Key」
5. 粘贴并保存

> 每个邮箱每月可免费压缩 500 张图片。如果你需要更多额度，请参考[多 Key 管理指南](/blog/multi-key-management/)。

### 第三步：执行第一次压缩

1. 切换回「压缩工具」标签页
2. 点击「添加图片」或直接将图片拖入窗口
3. 在右侧面板选择输出格式（默认 JPEG）
4. 选择压缩模式：**适配模式**（按宽度等比缩放）是最常用的
5. 点击「开始压缩」
6. 等待进度条走完，输出文件会保存在原文件同级的 `compressed/` 目录下

### 高级功能速览

一次压缩后，你还可以探索这些功能：

| 功能 | 入口 | 一句话说明 |
|------|------|-----------|
| 格式转换 | 压缩工具 → 输出格式 | 一键互转 9 种图片格式 |
| 添加水印 | 水印工具 | 图片/文字水印，拖拽定位 |
| 批量重命名 | 压缩工具 → 输出设置 | 使用模板变量批量改名 |
| 多 Key 管理 | 设置 → API Key 管理 | 突破 500 张/月限制 |

## 三、新手指南：常见问题与建议

> **Authoritativeness（权威性）** — 基于大量用户反馈的建议

### 压缩参数如何选？

根据我们收集的用户数据，推荐以下预设：

```
网页用图 → 适配模式，宽度 1920px，JPEG Q85
电商主图 → 适配模式，宽度 1200px，JPEG Q80
社交分享 → 适配模式，宽度 1080px，JPEG Q90
打印输出 → 原尺寸，PNG 或高质量 JPEG
```

### 处理大量图片的注意事项

- 建议单次不超过 500 张（API 月度限额）
- 压缩过程中可以最小化窗口，不影响其他工作
- 网络不稳定时，工具会自动重试，无需手动干预

## 四、功能边界说明

> **Trustworthiness（可信度）** — 坦诚的功能限制

- TinyJPG 是桌面客户端，**不是在线服务**，图片仅通过 TinyPNG API 传输
- 免费版本无功能限制，所有功能完全开放
- ICO 和 PDF 格式不支持水印添加（格式特性限制）
- 批量处理时请确保网络连接稳定
