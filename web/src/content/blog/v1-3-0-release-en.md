## What's New in v1.3.0

TinyJPG Compressor v1.3.0 is officially released! Here are the highlights:

### ✨ New Features

1. **AVIF Format Support** — Added AVIF image format output for smaller file sizes while maintaining quality
2. **Enhanced Format Conversion** — Now supports 9 formats: JPEG, PNG, WebP, GIF, TIFF, BMP, AVIF, ICO, PDF

### 🎨 Improvements

- Smoother watermark drag-and-drop experience
- Real-time API quota refresh
- Improved compression queue management for batch processing

### 🐛 Bug Fixes

- Fixed display issues on high-DPI screens
- Fixed parsing errors for certain special image formats
- Fixed watermark preview rendering anomalies
