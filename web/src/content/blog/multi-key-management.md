## 01. 多 Key 是怎么自动轮询的

TinyOpt 的 KeyManager 在后台做了一件事：多个 Key 轮流用，谁有空谁上。

**核心逻辑**：
- 所有 Key 排成一个环，按顺序分配任务
- 额度用完的 Key 自动跳过
- 无效 Key 自动禁用，不重复尝试
- 每个 Key 同一时间只处理一张图，互不干扰

**并发模型**：
```
可用 Key 数 → 决定并发数（最多 3 个）
3 个 Key → 3 张图同时压
7 个 Key → 还是 3 线程（API 频率限制），但 Key 多了轮流用不怕超额
```

**异常处理**：

| 问题 | 工具怎么处理 |
|------|------------|
| 额度用完 | 自动禁用该 Key，切到下一个 |
| API 密钥无效 | 自动禁用，不再重试 |
| 网络超时 | 释放 Key，等一秒重试 |
| 所有 Key 都超限 | 提示"可用密钥额度已用完"，不白等 |

## 02. 从哪里搞到多个免费 Key

每个 TinyPNG 邮箱账号 = 一个免费 Key。以下方式可以注册多个账号：

**推荐方式**：Gmail 别名
```
yourname+1@gmail.com
yourname+2@gmail.com
yourname+3@gmail.com
...
```
所有邮件会发到同一个主邮箱，不需要管理多个收件箱。

**配合方式**：和家人朋友共享，每人注册一个 Key 放一起用。

**初始建议**：先注册 3-5 个，够日常使用后按需补充。

## 03. 日常怎么管理这些 Key

配置策略很简单：
- 统一把月限额设为 500
- 给每个 Key 写个备注（"工作用""备用"）
- 压缩前点一下「刷新用量」检查剩余额度
- 保留至少 1 个备用 Key

Key 只存在你本地电脑的配置文件里，不会上传到任何云端。

## 常见问题

**01. 多 Key 并发会不会超过 TinyPNG API 频率限制？**
不会。TinyOpt 最多 3 线程并发，在 TinyPNG API 的合理调用频率范围内。

**02. 共享 Key 是什么？安全吗？**
TinyOpt 内置了 2 个公共共享 Key。方便你下载就能直接用，但建议自行注册 Key 以获得稳定服务。

**03. 如果某个 Key 在压缩过程中额度用完了怎么办？**
KeyManager 会自动检测到额度耗尽，禁用该 Key 并切换到下一个可用 Key，压缩任务不会中断。

**04. Key 会泄露吗？**
Key 只存储在本地的 `.tinypng_compressor_config.json` 文件中，工具不会向任何第三方发送你的 Key。

**05. 每月额度什么时候重置？**
TinyPNG 的免费额度按月重置，具体日期以首次注册时间为准。你在工具中点击「刷新用量」即可看到最新数据。
