## Background

A freelance designer needed to send large batches of preview images to clients while protecting their work from unauthorized use.

## Solution

Using TinyJPG's watermark tool:

1. Upload design mockups and enable batch compression
2. Add text watermark (author name + website URL)
3. Adjust opacity to 30% and position to bottom-right
4. One-click batch output

## Results

- 200+ images processed in under 3 minutes per batch
- Professional-looking watermarks that don't interfere with preview
- Effectively reduced unauthorized use of portfolio work
